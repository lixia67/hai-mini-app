# 美萍数据迁移工具

M3 只迁移两类数据：图书基础资料与当前库存。历史会员、订单、财务、租借、供应商、佣金等旧数据不进入新系统。

迁移流程固定为：

`raw archive → staging → normalize/validate/dedupe → review → import → reconciliation`

## 原则

- 原始导出文件只读归档，不直接修改。
- 每次迁移必须有 batch_id 与源文件 checksum，支持幂等重跑。
- staging 与正式表隔离；校验失败的数据不得进入正式库。
- ISBN、书名、出版社、作者、分类、门店、库存数量等字段需要显式映射。
- 库存导入必须可追溯，并在正式导入后生成 reconciliation 报告。
- 切换完成后，新系统成为唯一数据源。

## 目录约定

- `raw/`：本地原始导出文件，不提交真实业务数据到 Git。
- `src/`：解析、标准化、校验、去重与导入逻辑。
- `reports/`：本地生成的审查/对账报告，不提交真实数据。

## 尚需业务提供

开始真实字段映射前，需要至少一份美萍“图书资料”和“当前库存”导出样例（可脱敏），并确认美萍版本、导出格式以及门店编码含义。
