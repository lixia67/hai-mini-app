# M3 美萍数据迁移执行计划

## 目标

把旧美萍系统中的图书基础资料与当前库存安全迁移到小海童话 2.0，并保留完整批次、校验和对账记录。

## 范围

迁移：
- 图书基础资料
- 当前门店库存

不迁移：
- 历史会员
- 历史订单
- 历史财务
- 历史租借
- 历史供应商
- 历史佣金
- 其他旧系统历史流水

## 阶段

1. Raw Archive：保存原始导出文件与 SHA-256 checksum。
2. Staging：按源文件逐行解析，不直接写正式业务表。
3. Normalize：统一编码、空值、ISBN、数字、日期、门店标识等。
4. Validate：检查必填字段、非法库存、重复 ISBN/记录、未知门店。
5. Dedupe：按确认后的业务规则生成候选合并结果。
6. Review：输出人工审查报告，阻止异常批次进入正式库。
7. Import：使用数据库事务/幂等键写入图书与初始库存。
8. Reconciliation：对比源记录数、导入数、跳过数、错误数与各门店库存合计。

## Gate

真实导入代码开始前必须取得至少一份脱敏导出样例，并确认：
- 美萍版本
- 图书导出格式（CSV/XLS/XLSX/DBF/其他）
- 库存导出格式
- 源字段含义
- 门店代码与新系统门店 ID 的映射
- ISBN 缺失或重复时的处理规则

## 验收

- 同一批次可安全重跑，不重复创建图书或库存。
- 校验失败记录不会进入正式数据。
- 每次正式导入都有 batch_id、源文件 checksum、统计结果和异常明细。
- 各门店库存导入前后可以逐店对账。
- 切换完成后，新系统作为唯一库存数据源。
