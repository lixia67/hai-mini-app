# 小海童话 2.0 微信小程序

小海童话 2.0 是围绕「内容 + AI 创作 + 图书商城 + 动画 + 线下门店 + 分享佣金」构建的微信小程序项目。

## 产品模块

- **首页**：核心内容、商品、动画、AI 创作及活动入口。
- **小海商城**：图书商城、商品详情、购物车、订单和微信支付。
- **小海童话动画**：动画列表、动画详情、免费观看/试看、付费观看和我的已购。
- **小海AI——所享即所想**：提供故事创作、绘本创作和动画创作能力。
- **胖竹全球**：全球门店、地图找店、图书查询、门店库存、图书租借、商品与服务购买、到店自提、同城配送及加盟推广。
- **分享与佣金**：支持内容/商品分享、推广关系及佣金体系。
- **我的**：统一管理订单、动画、AI 作品、租借、佣金和会员信息。

## 项目目标

通过微信小程序连接原创童话内容、AI 内容生成、数字动画、图书电商与全球线下门店，让用户可以完成从内容发现、AI 创作、购买/观看，到门店查询、租借和分享推广的一体化体验。

## 规划文档
